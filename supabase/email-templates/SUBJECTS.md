# MatchUp email subjects

Paste these subjects into the corresponding hosted Supabase Auth email templates.

| Supabase template | MatchUp subject |
|---|---|
| Confirm signup | Confirm your MatchUp email address |
| Reset password | Reset your MatchUp password |
| Change email address | Confirm your new MatchUp email address |
| Magic link | Your MatchUp sign-in link |
| Invite user | You have been invited to MatchUp |
| Reauthentication | Your MatchUp verification code |
| Password changed notification | Your MatchUp password was changed |
| Email changed notification | Your MatchUp email address was changed |
| Phone changed notification | Your MatchUp phone number was changed |
| MFA factor enrolled notification | A new MatchUp verification method was added |
| MFA factor unenrolled notification | A MatchUp verification method was removed |
| Identity linked notification | A MatchUp sign-in method was linked |
| Identity unlinked notification | A MatchUp sign-in method was removed |

Do not change the Supabase template variables inside the HTML. They are required for real authentication links/codes.
